NAVYATHA RAMESWARAPU — PORTFOLIO

FILES
- index.html: page structure
- style.css: responsive styling
- script.js: mobile menu, reveal animation, contact form
- assets/profilephoto.jpg: place your portrait here (keep this exact filename)
- assets/resume.pdf: your résumé PDF, linked by the Download résumé button
- assets/skills/: local technology logos used in the grouped skills section

RUN
Open index.html with VS Code Live Server. Keep the assets folder beside index.html.

CONTACT FORM
The form opens the visitor's default email app with the fields filled in; it does not send mail automatically. For automatic web form delivery, connect a form service/backend.

EDITING
Update project descriptions and internship details in index.html to reflect your exact work.
